# 💱 Перевод валют

Сайт для перевода валют с актуальными курсами. Показывает курсы к рублю, конвертирует по текущему курсу и запоминает, какие валюты я выбирала в прошлый раз.

## 🔗 Ссылка

[Открыть сайт](https://magglik.github.io/currency-converter/)

## Что умеет

- Переводит из любой валюты в любую
- Показывает текущий курс между выбранными валютами
- Курсы подтягиваются с сайта ЦБ РФ
- Есть кнопка, чтобы поменять валюты местами
- Запоминает последние выбранные валюты (через localStorage)
- Показывает курсы популярных валют к рублю
- Внизу видно, когда курсы обновились
